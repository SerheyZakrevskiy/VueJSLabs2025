# Лабораторна робота №5

## Тема роботи

Розробка landing page для SaaS-продукту з використанням **Vue 3**, **Vite**, **TypeScript** та **PrimeVue**.

## Мета роботи

Ознайомитися з можливостями бібліотеки компонентів **PrimeVue**, навчитися інтегрувати готові UI-компоненти у Vue-застосунок, а також створити власний плагін **CopyToClipboardPlugin** та використати його у декількох сценаріях інтерфейсу.

## Завдання роботи

У межах лабораторної роботи було необхідно:

- створити landing page для SaaS-продукту;
- використати бібліотеку **PrimeVue**;
- реалізувати основні секції лендингу;
- додати секцію тарифів із міні-калькулятором;
- створити контактну форму з валідацією;
- реалізувати власний плагін **CopyToClipboardPlugin**;
- використати плагін щонайменше у 2–3 місцях застосунку.

## Опис реалізованого landing page

У межах роботи було розроблено landing page для умовного SaaS-сервісу **TaskFlow**, який призначений для керування задачами, командами та дедлайнами.

- **Reviews** — секція відгуків користувачів;
- **FAQ** — список поширених запитань;

## Налаштування PrimeVue

У файлі `main.ts` було підключено:

- **PrimeVue**
- тему оформлення **Aura**
- **ToastService**
- **PrimeIcons**

### Приклад підключення

```ts
import { createApp } from "vue";
import App from "./App.vue";

import PrimeVue from "primevue/config";
import Aura from "@primeuix/themes/aura";
import ToastService from "primevue/toastservice";
import "primeicons/primeicons.css";

import CopyToClipboardPlugin from "./plugins/copyToClipboard";

const app = createApp(App);

app.use(PrimeVue, {
  theme: {
    preset: Aura,
  },
});

app.use(ToastService);
app.use(CopyToClipboardPlugin);

app.mount("#app");
```

## Власний плагін CopyToClipboardPlugin

У межах лабораторної роботи було реалізовано власний плагін **CopyToClipboardPlugin**.

### Призначення плагіна

Плагін дозволяє копіювати текст у буфер обміну за допомогою `navigator.clipboard.writeText()` та повертати результат виконання у вигляді `true` або `false`.

### Файл плагіна

```text
src/plugins/copyToClipboard.ts
```

### Основна логіка

- приймає рядок для копіювання;
- намагається записати текст у буфер обміну;
- у разі успіху повертає `true`;
- у разі помилки повертає `false`.
