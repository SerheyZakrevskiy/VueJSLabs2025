# Лабораторна робота №3

## Тема: Стилізація компонентів та роутинг у Vue.js

### Мета роботи

Ознайомитися з можливостями стилізації компонентів у Vue 3 та реалізувати багатосторінковий застосунок із маршрутизацією, перемиканням теми, анімаціями переходів і використанням `Teleport`.

---

## Опис проєкту

У межах лабораторної роботи було розроблено мінісайт новин **Vue News** на базі **Vue 3**, **Vue Router 4** та **Vite**.

Застосунок демонструє:

- стилізацію компонентів за допомогою `scoped styles`
- використання **CSS Modules**
- маршрутизацію між сторінками
- анімацію переходів між сторінками
- модальне вікно реклами через `Teleport`
- перемикання світлої та темної теми
- збереження теми в `localStorage`

---

## Використані технології

- **Vue 3**
- **Vue Router 4**
- **Vite**
- **TypeScript**
- **CSS / Scoped Styles / CSS Modules**

## Реалізований функціонал

### 1. Головна сторінка

На головній сторінці відображається список новин у вигляді карток.  
Кожна картка містить:

- зображення
- категорію
- дату
- заголовок
- короткий опис
- посилання **Read more** для переходу на сторінку детальної новини

### 2. Сторінка новини

Для кожної новини реалізована окрема сторінка виду:

```bash
/article/:id
```

На цій сторінці відображаються:

- велике зображення
- заголовок новини
- дата та категорія
- повний текст
- рекламний блок
- посилання повернення на головну сторінку

Якщо новину не знайдено, відображається повідомлення **Article not found**.

### 3. Сторінка About

Окрема інформаційна сторінка з описом проєкту та рекламним блоком.

### 4. Сторінка 404

Для неіснуючих маршрутів реалізовано сторінку **Not Found**.

### 5. Маршрутизація

У проєкті реалізовано такі маршрути:

- `/` — головна сторінка
- `/article/:id` — сторінка новини
- `/about` — інформаційна сторінка
- `/:pathMatch(.*)*` — сторінка 404

### 6. Перемикання теми

У шапці сайту реалізовано кнопку перемикання між:

- **Light mode**
- **Dark mode**

Обрана тема зберігається в `localStorage`, тому після перезавантаження сторінки вона не скидається.

### 7. Рекламні блоки

У застосунку реалізовано рекламні блоки на різних сторінках:

- на головній сторінці
- на сторінці About
- на сторінці новини

### 8. Модальне вікно через Teleport

Після натискання на кнопку в рекламному блоці відкривається модальне вікно.  
Модальне вікно реалізоване за допомогою:

````vue
<Teleport to="body">
Це дозволяє рендерити модальне вікно поза межами основної структури сторінки, що особливо зручно для реалізації overlay-елементів, які мають відображатися поверх усього інтерфейсу.

### 9. Анімації

У проєкті реалізовано такі анімаційні ефекти:

- анімація переходів між сторінками за допомогою компонента `<Transition>`
- анімація появи та закриття модального вікна реклами

Це покращує візуальне сприйняття інтерфейсу та робить взаємодію із застосунком більш плавною.

### 10. Стилізація

У роботі використано два основні підходи до стилізації компонентів:

- **Scoped styles** — для ізоляції локальних стилів окремих компонентів
- **CSS Modules** — для компонента картки новини `NewsCard.vue`

Такий підхід дозволяє поєднати зручність локальної стилізації з більш гнучким керуванням CSS-класами.
````
