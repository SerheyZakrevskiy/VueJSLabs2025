# Лабораторна робота №4

## Vue 3 + Pinia + Persisted State + i18n + VeeValidate

## Опис роботи

У межах цієї лабораторної роботи було розроблено клієнтський застосунок на базі **Vue 3**, який демонструє роботу зі станом застосунку через **Pinia**, збереження налаштувань через **pinia-plugin-persistedstate**, локалізацію за допомогою **vue-i18n**, а також валідацію форм через **VeeValidate** та **Yup**.  
Основний сценарій роботи застосунку охоплює перегляд товарів, взаємодію з кошиком, зміну мови інтерфейсу та заповнення профілю користувача з динамічним масивом телефонів. :contentReference[oaicite:0]{index=0}

---

## Мета роботи

Ознайомитися з практичним використанням:

- глобального стану в **Pinia**;
- збереження частини стану в **localStorage** через `pinia-plugin-persistedstate`;
- локалізації інтерфейсу за допомогою **vue-i18n**;
- побудови та валідації форм за допомогою **VeeValidate**;
- роботи з динамічними полями форми через `useFieldArray`;
- програмного встановлення помилок через `setFieldError`. :contentReference[oaicite:1]{index=1}

## Опис основних модулів

### `stores/settings.ts`

Містить налаштування застосунку.  
У цьому store зберігається поточна локаль (`locale`), а також використовується `persist`, щоб після оновлення сторінки обрана мова залишалася незмінною.

### `stores/cart.ts`

Містить логіку кошика.  
Store включає:

- масив товарів `items`;
- обчислення загальної кількості товарів `totalCount`;
- обчислення загальної вартості `totalPrice`;
- методи `add`, `remove`, `clear`.

### `i18n.ts`

Містить налаштування локалізації:

- підключення мов `ua` та `en`;
- `fallbackLocale`;
- модифікатори `upper`, `lower`, `capitalize`;
- кастомний модифікатор;
- синхронізацію локалі з `settings` store.

### `pages/ProductsPage.vue`

Сторінка відображення товарів.  
Користувач може додавати товари до кошика.

### `pages/CartPage.vue`

Сторінка кошика.  
Відображає список доданих товарів, їхню кількість, загальну суму, а також дозволяє очищати кошик або видаляти окремі товари.

### `pages/ProfilePage.vue`

Сторінка профілю з формою.  
Реалізована через **VeeValidate** та **Yup**.  
Форма містить поля:

- ім’я;
- `email`;
- дата народження;
- адреса;
- список телефонів.

Також реалізовано:

- `handleSubmit`
- `resetForm`
- `useFieldArray`
- `setFieldError`

## Локалізація

У проєкті реалізовано підтримку двох мов:

- `ua` — українська
- `en` — англійська

Користувач може перемикати мову через інтерфейс застосунку.  
Обрана мова зберігається в `localStorage`, тому після оновлення сторінки локаль не скидається.  
Для демонстрації можливостей `vue-i18n` використано стандартні модифікатори та кастомний модифікатор.

---

## Валідація форми

Для сторінки профілю використано:

- `useForm`
- `validationSchema`
- `handleSubmit`
- `resetForm`
- `useFieldArray`
- `setFieldError`

Схема валідації побудована за допомогою **Yup**.  
Перевіряються такі умови:

- ім’я є обов’язковим і має мінімальну довжину;
- `email` має бути у коректному форматі;
- дата народження має бути валідною;
- вік користувача має бути не менше 16 років;
- адреса є обов’язковою;
- необхідно вказати хоча б один телефон;
- телефон повинен відповідати допустимому формату.

Також реалізовано кнопку для емуляції серверної помилки, яка встановлює помилку для поля `email` за допомогою `setFieldError`.
